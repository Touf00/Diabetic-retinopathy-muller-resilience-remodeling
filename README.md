# Cross-species stress-testing of an early Müller resilience program in diabetic retinopathy

Reproducibility code and frozen analysis outputs supporting the computational study:

**Cross-species stress-testing of an early Müller resilience program reveals state-dependent remodeling in diabetic retinopathy**

This repository tests whether an experimentally defined early Müller glial resilience-associated transcriptional program is conserved across later diabetic retinal states, species, retinal compartments, and human experimental systems.

The analysis integrates:
- early diabetic mouse Müller-cell single-cell RNA-seq
- longitudinal mouse whole-retina RNA-seq
- chronic mouse Müller-cell single-cell RNA-seq
- donor-level human Müller-cell pseudobulk analysis
- stage- and region-resolved human retinal transcriptomics
- human retinal organoids
- longitudinal rat Müller-cell data

The Early184 signature and prespecified IFN6, Retinoid5, and ECM13 modules were locked before external validation and were not redefined based on downstream results.
